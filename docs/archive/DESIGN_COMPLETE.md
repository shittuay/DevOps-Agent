### Design System Specifications

**Color Palette:**
```css
--bg-primary: #0a0e1a        /* Deep space black */
--bg-secondary: #111827       /* Secondary dark */
--bg-elevated: #212d3f        /* Elevated surfaces */
--glass-bg: rgba(26, 35, 50, 0.7)  /* Glass effect */
--accent-primary: #ff6b35     /* Vibrant orange */
--accent-electric: #00d4ff    /* Electric blue */
--text-primary: #f8fafc       /* Primary text */
--text-secondary: #cbd5e1     /* Secondary text */
--gradient-primary: linear-gradient(135deg, #ff6b35 0%, #f7931e 100%)
```

**Typography Stack:**
- **Syne** (800, 700, 600): Headers, titles, brand elements
- **IBM Plex Mono** (600, 500, 400): Technical elements, labels, code
- **Outfit** (700, 600, 500, 400, 300): Body text, UI elements

**Signature Effects:**
- Animated grid background (50px grid, 20s infinite movement)
- Gradient mesh overlays (orange top-left, blue bottom-right)
- Glassmorphism (backdrop-filter: blur(20-40px))
- Shimmer animations on icons
- Staggered fade-in animations (0.1s-0.4s delays)
- Button ripple effects on hover
- 3D hover transforms (translateY, scale, rotate)

**Responsive Breakpoints:**
- 768px (tablets)
- 480px (mobile)
