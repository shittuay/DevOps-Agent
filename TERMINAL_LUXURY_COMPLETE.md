## 🎨 Terminal Luxury Design System

### Color Palette
```css
/* Dark Theme (Default) */
--bg-primary: #0a0e1a          /* Deep space black */
--bg-secondary: #111827         /* Secondary dark */
--bg-elevated: #212d3f          /* Elevated surfaces */
--glass-bg: rgba(26, 35, 50, 0.7)  /* Glass effect */

--accent-primary: #ff6b35       /* Vibrant orange */
--accent-electric: #00d4ff      /* Electric blue */
--accent-success: #10b981       /* Success green */
--accent-warning: #f7931e       /* Warning orange */
--accent-error: #ef4444         /* Error red */

--text-primary: #f8fafc         /* Primary text */
--text-secondary: #cbd5e1       /* Secondary text */
--text-tertiary: #64748b        /* Tertiary text */

/* Light Theme */
--bg-primary: #f8fafc           /* Light slate */
--bg-secondary: #ffffff         /* White */
--glass-bg: rgba(255, 255, 255, 0.85)  /* Light glass */
--text-primary: #0f172a         /* Dark slate */
```

### Typography Stack
- **Syne** (800, 700, 600): Headers, titles, brand, numbers
- **IBM Plex Mono** (600, 500, 400): Technical labels, code, monospace
- **Outfit** (700, 600, 500, 400, 300): Body text, UI elements

### Signature Effects
1. **Animated Grid Background**
   - 50px grid pattern
   - 20s infinite movement animation
   - 0.3 opacity for subtle effect

2. **Gradient Mesh Overlays**
   - Orange radial at top-left (0% 0%)
   - Blue radial at bottom-right (100% 100%)
   - 15% opacity for depth

3. **Glassmorphism**
   - `backdrop-filter: blur(20-40px)`
   - Semi-transparent backgrounds
   - Subtle border highlights

4. **Shimmer Animations**
   - On logo icons (3s infinite)
   - On avatars (3s infinite)
   - Diagonal sweep effect

5. **Staggered Reveals**
   - 0.1s-0.6s delays on lists
   - Fade and slide-up motion
   - Smooth easing curves

6. **Button Ripples**
   - Expanding circle on hover
   - White overlay at 30% opacity
   - 0.6s transition duration

7. **3D Transforms**
   - translateY(-2px to -8px) on hover
   - scale effects on interactive elements
   - Smooth shadow transitions

### Responsive Breakpoints
- **768px**: Tablets - Collapsing layouts, icon-only buttons, flex columns
- **480px**: Mobile - Single columns, larger touch targets, hidden text
