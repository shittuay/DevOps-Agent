How to get Azure credentials:

  • Go to Azure Portal (portal.azure.com)
  • Navigate to Azure Active Directory
  • Go to "App registrations" and create a new registration
  • Copy the Application (client) ID and Directory (tenant) ID
  • Under "Certificates & secrets", create a new client secret
  • Assign the appropriate roles in your subscription's IAM

  • Select or create a project
  • Navigate to "IAM & Admin" → "Service Accounts"
  • Create a new service account with appropriate roles
  • Click on the service account and go to "Keys"
  • Create a new JSON key and download it
  • Copy the entire JSON content and paste it above
