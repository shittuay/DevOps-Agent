Setup Instructions

Slack Setup

  1. Create a Slack App at api.slack.com/apps
  2. Enable Events API and subscribe to: app_mention, message.im
  3. Create a Slash Command /devops pointing to the commands URL
  4. Add OAuth scopes: chat:write, commands, app_mentions:read
  5. Set SLACK_BOT_TOKEN and SLACK_SIGNING_SECRET environment variables

Microsoft Teams Setup

  1. Create a Bot registration in Azure Portal
  2. Configure the messaging endpoint to point to the Teams messages URL
  3. Create an App Package with the bot configuration
  4. Install the app in your Teams workspace
  5. Set TEAMS_APP_ID and TEAMS_APP_PASSWORD environment variables
