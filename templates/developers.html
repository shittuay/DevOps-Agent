Developer API · v1

Build on DevOps Agent

Access 258 cloud infrastructure tools and a full AI DevOps agent programmatically. Automate AWS, Kubernetes, Azure, and GCP operations from your own code.

API v1 — Live 258 tools SSE streaming

Authentication

Every API request (except /v1/health) requires an API key passed in the X-API-Key header. Generate keys in your API Gateway dashboard.

i API keys are scoped to your account. All data returned is isolated to your credentials — you can never read another user's infrastructure or conversations.
HTTP HEADER 
X-API-Key: doa_live_xxxxxxxxxxxxxxxxxxxxxxxx
CURL 
curl https://devopsagent.io/api-gateway/v1/agent \
  -H "X-API-Key: doa_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{"message": "List all EC2 instances in us-east-1"}'

Response headers

Every authenticated response includes rate-limit headers so you can track consumption.

RESPONSE HEADERS 
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 986
# On 429 — amount of seconds to wait before retrying
Retry-After: 3600

Run the Agent

Send a natural-language DevOps request and get a structured response with tools used and credits consumed.

POST /api-gateway/v1/agent Run AI DevOps agent API key required Professional+

Processes your message through the full DevOps agent — the AI decides which tools to call, calls them against your cloud credentials, and returns a complete response.

Request body

FieldTypeRequiredDescription
message string required Natural language DevOps instruction. Max 10,000 chars.
conversation_id string optional Alphanumeric string (max 64 chars) to continue a conversation thread. Prefix api- is added automatically.
REQUEST 
{
  "message": "List all EC2 instances in us-east-1 and flag any that have been stopped for over 7 days",
  "conversation_id": "my-session-01"
}
RESPONSE 200 
{
  "response": "Found 8 EC2 instances in us-east-1. 2 instances have been stopped for over 7 days: i-0abc (stopped 14 days), i-0def (stopped 9 days). Recommend terminating or snapshotting these.",
  "tools_used": ["list_ec2_instances", "describe_ec2_instance"],
  "credits_remaining": 47,
  "conversation_id": "api-my-session-01"
}

Streaming Agent (SSE)

Same as /v1/agent but streams the response token-by-token via Server-Sent Events. Ideal for building real-time CLIs and terminal UIs.

POST /api-gateway/v1/agent/stream Stream agent response via SSE API key required Professional+

Set Accept: text/event-stream. The connection stays open and emits events as the agent thinks, calls tools, and generates its response.

SSE event types

TypePayload
chunk {"type":"chunk","content":"..."} — text token
tool {"type":"tool","name":"list_ec2_instances"} — tool call started
done {"type":"done","tools_used":[...],"credits_remaining":N,"conversation_id":"..."}
error {"type":"error","message":"..."}
PYTHON (SSE) 
import httpx, json

with httpx.stream(
    "POST",
    "https://devopsagent.io/api-gateway/v1/agent/stream",
    headers={"X-API-Key": "doa_live_xxxx"},
    json={"message": "Scale the payments deployment to 5 replicas"},
) as r:
    for line in r.iter_lines():
        if line.startswith("data: "):
            event = json.loads(line[6:])
            if event["type"] == "chunk":
                print(event["content"], end="", flush=True)
            elif event["type"] == "tool":
                print(f"\n[tool] {event['name']}")
            elif event["type"] == "done":
                print(f"\n\nCredits left: {event['credits_remaining']}")

PYTHON · pip install httpx 
import httpx

API_KEY = "doa_live_xxxx"
BASE    = "https://devopsagent.io/api-gateway"

def ask(message: str, conversation_id: str = None) -> dict:
    resp = httpx.post(
        f"{BASE}/v1/agent",
        headers={"X-API-Key": API_KEY},
        json={"message": message, "conversation_id": conversation_id},
        timeout=60,
    )
    resp.raise_for_status()
    return resp.json()


# Example: check EKS cluster health
result = ask("How many pods are running in the production namespace?")
print(result["response"])
print("Tools used:", result["tools_used"])
print("Credits left:", result["credits_remaining"])


# Example: list all AWS tools available
tools = httpx.get(
    f"{BASE}/v1/tools",
    headers={"X-API-Key": API_KEY},
    params={"provider": "aws"},
).json()
print(f"AWS tools: {tools['total']}")


# Example: execute a specific tool directly (Professional+ only)
result = httpx.post(
    f"{BASE}/v1/execute",
    headers={"X-API-Key": API_KEY},
    json={"tool": "list_ec2_instances", "params": {"region": "eu-west-1"}},
).json()
print(result["result"])
NODE.JS · npm install node-fetch 
const fetch = require('node-fetch');

const API_KEY = 'doa_live_xxxx';
const BASE    = 'https://devopsagent.io/api-gateway';

// Run the agent
async function ask(message, conversationId) {
  const res = await fetch(`${BASE}/v1/agent`, {
    method: 'POST',
    headers: {
      'X-API-Key': API_KEY,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ message, conversation_id: conversationId }),
  });
  return res.json();
}

// SSE streaming
async function stream(message) {
  const res = await fetch(`${BASE}/v1/agent/stream`, {
    method: 'POST',
    headers: { 'X-API-Key': API_KEY, 'Content-Type': 'application/json' },
    body: JSON.stringify({ message }),
  });

  for await (const chunk of res.body) {
    const lines = chunk.toString().split('\n');
    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const event = JSON.parse(line.slice(6));
        if (event.type === 'chunk') process.stdout.write(event.content);
        else if (event.type === 'done') console.log('\n✓', event.credits_remaining, 'credits left');
      }
    }
  }
}

ask('How much did my AWS bill cost last month?').then(console.log);
