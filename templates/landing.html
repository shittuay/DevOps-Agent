Developer API

Automate the automator.
Build on top of DevOps Agent.

Professional and Business subscribers get API key access to the full 749-tool agent. Call it from scripts, CI pipelines, internal tools, or your own SaaS products.

01
Generate an API Key
From Settings → API Keys, create a named key with optional scopes and expiry. Your key is shown once — store it securely.
02
POST a Message
Send {"message": "Scale my ECS service to 5 tasks"} to /api-gateway/v1/agent with your key in the X-API-Key header.
03
Get the Response
Receive the agent's text response, the list of tools executed, and your updated credit balance. Use conversation_id to keep multi-turn context across calls.
curl example
# Call the agent via REST API
curl -X POST https://devopsagent.io/api-gateway/v1/agent \
-H "X-API-Key: doa_your_key_here" \
-H "Content-Type: application/json" \
-d '{"message": "List all RDS instances in us-east-1"}'

# Response
{
"response": "Found 3 RDS instances...",
"tools_used": ["list_rds_instances"],
"credits_remaining": 1847,
