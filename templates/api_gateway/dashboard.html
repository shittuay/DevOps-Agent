Quick Start

Authentication

Include your API key in the X-API-Key header:

X-API-Key: doa_live_xxxxxxxxxxxx

Example Request

curl -X GET "{{ request.url_root }}api-gateway/v1/resources" \
  -H "X-API-Key: YOUR_API_KEY"

Available Endpoints

  • GET /api-gateway/v1/resources - List all resources
  • GET /api-gateway/v1/resources/:id - Get resource details
  • GET /api-gateway/v1/analytics/costs - Get cost analytics
