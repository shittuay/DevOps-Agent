Authentication

All API requests require an API key passed in the X-API-Key header:

X-API-Key: YOUR_API_KEY

Endpoints

GET /api-gateway/v1/resources

List all infrastructure resources

Response:
{"resources": [{"id": 1, "name": "...", "type": "ec2", "status": "running"}]}

GET /api-gateway/v1/resources/:id

Get a specific resource by ID

GET /api-gateway/v1/analytics/costs

Get cost analytics data

GET /api-gateway/v1/health

Health check endpoint (no authentication required)

Rate Limiting

API requests are rate limited to 1000 requests per hour per API key.

Rate limit headers are included in responses:

  • X-RateLimit-Limit: Maximum requests per hour
  • X-RateLimit-Remaining: Remaining requests
  • X-RateLimit-Reset: Unix timestamp when limit resets
